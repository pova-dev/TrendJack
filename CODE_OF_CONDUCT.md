# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Tl;dr

- Be sharp, be direct — that's the brand.
- Don't be cruel. Critique the code, the idea, the design — not the person.
- No harassment, dog-whistles, identity-based slights, or sustained disruption.
- Maintainers reserve the right to remove comments, close PRs, and ban
  accounts that violate these terms.

## Reporting

Report code-of-conduct violations to `conduct@trendjack.dev` (or open a
private GitHub security advisory). Include:

- What happened
- Where (issue/PR/commit URL)
- Who was involved
- Any prior context

Reports are confidential. We respond within 72 hours.
