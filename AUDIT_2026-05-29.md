# TrendJack Audit — 29 May 2026

Static + runtime audit of `workstreams/marketing/social/trendjack/`. Excludes `trendjack-backup-2026-04-30/`.

**Total findings:** 26 (4 BROKEN, 9 DEGRADED, 8 USELESS, 5 SUSPICIOUS)

---

## 🔴 BROKEN — fix before any prod-ish use

### B1. Cross-tenant board read leak
`app/api/boards/route.ts:10` → `lib/store.ts:336-339`
`prisma.board.findUnique({ where: { id } })` returns the board with no brandId/ownerId check. Any logged-in user from any org can `GET /api/boards?id=<any_id>` and read another org's board (columns, filters, name).
**Fix:** filter by `{ id, brandId: ctx.brand.id }`; 404 on mismatch.

### B2. Cross-tenant board write leak
`lib/store.ts:341-348` — `saveBoard` upserts on board id with no ownership check. `POST /api/boards` with another brand's id mutates their row.
**Fix:** require `existing.brandId === b.brandId` before update.

### B3. Dead "live" connector stub still in repo
`lib/connectors/x.ts:7-21` — `XConnector` always returns `{ ok: false, reason: 'live_not_implemented' }`. Not imported anywhere; the real impl is `x-official.ts`.
**Fix:** delete the file.

### B4. Test-connector route rejects valid sources
`app/api/connectors/test/[source]/route.ts:19` — `valid` list excludes `instagram` and `facebook`, but the registry exposes them. The "Test live" button on those rows always returns `400 invalid_source`.
**Fix:** add the two sources (and make `getConnector` return a clean null for unconfigured cases).

## 🟠 DEGRADED — half-built, will silently fail

### D1. Apify/Graph "official" Instagram/Facebook stubs ARE mocks
`lib/connectors/mock.ts:67-68, 74-75` — `apify_ig_stub`, `ig_graph_stub`, `apify_fb_stub`, `fb_graph_stub` are `MockConnector` instances badged `official`. If a non-POVA tenant configures the real env vars, they'll get POVA-flavored fake trends (Xiaomi launch, BGMI memes) silently. **Silent fabrication for non-POVA tenants.**
**Fix:** keep as `unconfigured` until real adapters land, or relabel `mock`.

### D2. Sheets integration fails exactly when configured
`lib/integrations/sheets.ts:26` — returns `{ ok: false, error: 'live_not_implemented' }` when `GOOGLE_SHEETS_PRIVATE_KEY` is set.
**Fix:** implement via `googleapis`, or hide Sheets from the UI.

### D3. Slack / Sheets / Notion creds have no UI
`lib/integrations/slack.ts:19-42`, `sheets.ts`, `notion.ts` — env-var only. Not in `ALLOWED_KEYS` in `app/api/credentials/route.ts`, not in the integrations panel. Only works for self-hosters with shell access.
**Fix:** add to the credentials editor or remove the code paths.

### D4. Webhooks swallow every failure
`lib/integrations/webhooks.ts:29` — empty catch on every fetch. Comment says retried by separate worker; that worker doesn't exist.
**Fix:** add `WebhookDelivery` Prisma model + retry worker, or at minimum log failures to the audit log.

### D5. Notion integration is just a webhook with a label
`app/api/integrations/[type]/route.ts:24-26` — the `notion` case calls `sendWebhook` (generic JSON POST). Notion API needs `Notion-Version` header + bearer auth — will fail.
**Fix:** wire `@notionhq/client`, or remove the case.

### D6. Nitter / Invidious default mirrors are mostly dead
`lib/connectors/nitter.ts`, `invidious.ts` — comments admit "Most well-known mirrors have either been blocked by X or shut down." Connectors fail with `no instances reachable` ~always without operator-configured instances.
**Fix:** surface as "expected to fail without self-hosted setup" in the `/connectors` UI rather than chip them `oss · active`.

### D7. Reddit has no OAuth, will 429 in prod
`lib/connectors/reddit.ts:18` — uses public JSON only; comment admits OAuth is "next step (not implemented yet)." Connector test passes once, fails under cron load.
**Fix:** implement OAuth via the `Credential` model.

### D8. OpenRouter referer leaks "localhost"
`lib/ai/provider.ts:246` + `lib/research/index.ts:147` — default `OPENROUTER_REFERER='http://localhost:3000'` sent to OpenRouter from production.
**Fix:** error if unset in prod, or default to a configurable canonical URL.

### D9. `stubVerifier` reports tautologies with confidence=1.0
`src/agents/verifier/stub.ts:11-41` — when no AI keys are configured, returns the trend title as a "claim" with confidence 1.0. UI consumers treating this as ground truth will be misled.
**Fix:** drop confidence to ~0.4 or label `provider: 'stub'` in the rationale.

## ⚪ USELESS — code that does nothing real

### U1. Every dashboard page exists at two URLs
`/scoring` ≡ `/settings/scoring`, `/alerts` ≡ `/settings/alerts`, `/audit` ≡ `/settings/audit`, `/connectors` ≡ `/settings/connectors`, `/integrations` ≡ `/settings/integrations`. Each top-level route adds TopBar and re-fetches brand context. **5 duplicate page trees.**
**Fix:** pick one canonical location (`/settings/X` is more discoverable) and `redirect()` the other.

### U2. Alerts page is decorative
`app/(dashboard)/alerts/page.tsx:7-12` — renders hardcoded `SAMPLE_RULES`. **Verified live**: alerts page shows the same 4 hardcoded rules regardless of brand. Prisma `AlertRule` model exists but is never read or written. No editor. Nothing fires.
**Fix:** ship the rule editor or hide both pages.

### U3. Dashboard connector status is always green
`app/(dashboard)/page.tsx:36-58` — hardcodes `ok: true, lastRunAt: new Date().toISOString()` for every connector. `ConnectorStatusBar` pills are decorative.
**Fix:** query real last-run state from the `Connector` model or a runtime registry.

### U4. Media router is an empty registry
`src/core/media/router.ts:1-108` — interface + registry, no adapters registered. `routeMediaJob()` always returns `{ ok: false, reason: 'no_adapter_available' }`.
**Fix:** wire one real adapter (Higgsfield is the obvious one — already used elsewhere in POVA), or move file to `/parked/`.

### U5. Architect DLQ never shipped
`src/agents/architect/index.ts:4` — file header promises DLQ for unrecoverable failures. No DLQ code exists.
**Fix:** implement or remove the TODO.

### U6. `generateDraftsLive` is an unreachable throw
`lib/ai/anthropic.ts:95-97` — throws `not_implemented_in_phase_1`. Real impl lives in `draft-gen.ts`; this stub is never called.
**Fix:** delete the stub function.

### U7. Three Prisma models with zero reads/writes
`prisma/schema.prisma`:
- `Connector` (lines 295-306) — superseded by org-level `Credential` + `pickActive()` registry
- `AlertRule` (271-280) — see U2
- `ApprovalRule` (282-293) — never queried
**Fix:** drop in the next migration.

### U8. `lib/scoring/engine.ts` shim is load-bearing legacy
Reexport-only shim → `src/core/scoring`. CLAUDE.md says Phase 11 deletes it. ~20 modules (`lib/seed.ts`, `lib/ingest.ts`, …) still import from the shim instead of the new path.
**Fix:** migrate imports; delete shim.

## 🟡 SUSPICIOUS — needs verification

### S1. Copilot leaks cross-tenant drafts
`app/api/copilot/route.ts:42` — `listDrafts()` called with no `trendId` and no `brandId` filter. Returns all drafts across every brand/org and stuffs them into the copilot's user payload.
**Fix:** `listDrafts(undefined, ctx.brand.id)` — add brandId filtering at the store level.

### S2. Queue page violates hydration rule
`app/(dashboard)/queue/page.tsx:49, 57` — uses `timeUntil()` and `relTime()` directly in render. CLAUDE.md hard-rule 10 mandates the `now` state pattern. Same risk in `app/(dashboard)/audit/page.tsx:47`.
**Fix:** gate via the `now` state pattern from `TrendCard.tsx`.

### S3. Open cron-tick if both tokens unset
`app/api/cron-tick/route.ts:23-36` — if neither `CRON_SECRET` nor `TJ_CRON_TOKEN` is set, the route is open. Middleware already allowlists it. In a Vercel deploy where someone forgets, anyone can trigger ingest + AI spend across every brand.
**Fix:** refuse to start in production if both unset.

### S4. `/api/devlog` open if NODE_ENV mis-set
`middleware.ts:24-31` allowlists `/api/devlog`; route guards only via `NODE_ENV !== 'production'`. One env-typo and prod gets an open log relay.
**Fix:** belt-and-suspenders — also require an auth token.

### S5. `.env.example` advertises unread keys
`.env.example:27` declares `TIKTOK_API_KEY` — zero references in `lib/`. TikTok runs through RSSHub only.
**Fix:** prune `.env.example` to keys the code actually consumes.
